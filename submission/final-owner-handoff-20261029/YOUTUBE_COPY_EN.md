## Title (under 100 characters)

AegisLand: Evidence Review for Physical AI | NVIDIA Nemotron on Nebius Token Factory

## Description

When a simulated drone abandons its route, the operator needs to know why — and needs proof.

AegisLand Evidence Review turns saved Physical AI simulation evidence into a source-linked review workflow. Pick a scenario, jump to a key moment, and the replay seeks to that frame while the workbench shows the original trace line behind the decision: action, approval state, execution flag and evidence ID.

NVIDIA Nemotron 3 Super, served through Nebius Token Factory, selects which record to review and which check to run. Local code validates the citation and judges the recorded fact. The model never gets a command channel.

Built for the Nebius × NVIDIA Global AI Hackathon 2026 (Physical AI).

Code: https://github.com/Cyberchopin/aegisland-nebius-2026

Stack: Python (standard library), HTML, JavaScript, JSONL, SHA-256, Nebius Token Factory, NVIDIA Nemotron 3 Super. The OpenCV simulation is earlier AegisLand work.

Honest limitations: all scenarios are synthetic simulation; no real drone hardware was operated. The live review shown is one bounded, recorded request, not a measure of model accuracy, flight certification or a running service. Verdicts in the workbench are deterministic checks, not model output.
