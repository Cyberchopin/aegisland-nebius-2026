# Three-sentence pitch

## English

When a simulated drone suddenly changes its action, AegisLand lets an operator trace that decision back to the exact video frame and source record behind it. NVIDIA Nemotron on Nebius Token Factory picks which record to review and which check to run, while local code validates the citation and judges the recorded fact. The model can point at evidence but can never issue a command — so every answer is fast, cited and verifiable.

## 中文解释

第一句讲问题和产品：无人机仿真突然改变动作时，AegisLand 能把这个决策追溯到对应的视频帧和原始记录。
第二句讲 AI 怎么用：Nebius 上的 Nemotron 负责选"看哪条记录、做哪种检查"，本地代码负责验证引用、判断事实。
第三句讲为什么可信：模型只能"指"证据，永远不能发指令，所以每个答案都快、带引用、能验证。

## 30-second spoken version

> A drone simulation is flying home on low battery — then suddenly switches to an evasive hold. Why? AegisLand answers that with proof. Pick the moment, and the replay jumps to the exact frame while the original trace line appears beside it: the action, the approval state, and whether anything really executed. NVIDIA Nemotron on Nebius Token Factory picks which record to review; our local code checks the citation and judges the fact. The model points. Our code checks. Nothing it says can ever move a drone.
